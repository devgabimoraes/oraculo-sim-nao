Sobre o projeto

Este projeto é inspirado no canal do instagram da @juliajstudioo

O canal posta semanalmente perguntas sobre vários temas enviadas pelo público

Por meio da radiestesia mais de 2 mil perguntas já foram respondidas em SIM, NÃO ou INDIFERENTE.

O que o sistema faz?

  • Pesquisa por palavras chave
  • Realiza busca por IDs
  • Realiza busca sem acentos
  • Realiza busca por perguntas relacionadas

Você pode usar o sistema para pesquisar os temas de maior interesse antes de submeter suas próprias perguntas.

Tecnologias Utilizadas

O sistema está sendo desenvolvido para otimizar o uso de diferentes tecnologias

Tecnologia Descrição
mySQL Banco de dados onde estão armazenadas as perguntas e respostas
CSharp Primeira linguagem de programação para o desenvolvimento do backend
Python Segunda linguagem para o desenvolvimento do backend
JSON Formato de dados para intercâmbio entre o backend e o frontend
HTML5 Linguagem de marcação para o desenvolvimento do frontend
CSS Linguagem de estilo para o desenvolvimento do frontend
JavaScript Linguagem de programação para o desenvolvimento do frontend

Toda a documentação do sistema está disponível no repositório do GitHub.

Evolução do Sistema

O sistema está em constante evolução, e como o foco principal é juntar o útil ao agradável, ele está sendo usado para treino de skills.

  1. Transcrição dos áudios
  2. Criação do banco de dados com JSON
  3. Desenvolvimento do backend em C#
  4. Desenvolvimento do backend em Python
  5. Desenvolvimento do frontend em HTML5

Futuramente os dados serão estruturados em SQL, o que permitirá uma melhor organização e consulta das informações.
